# B-Manager

**B-Manager** は、Unity プロジェクト内のアセットと BOOTH などの販売ページ情報を紐づけて管理するエディタ拡張ツールです。

---

## 【重要】VCC版移行に伴うデータ互換性について（必ずお読みください）

**VCC対応以前のバージョン（旧版）をご利用の方へ**

本バージョンよりデータ保存の仕様が変更されました。そのため、**旧バージョンからの自動データ移行機能はありません。**

- VCC管理へ移行（本パッケージを導入）した場合、以前のバージョンで登録していたデータは**破損（参照不可）状態**となります。
- 大変お手数ですが、VCC版導入後は**すべてのアイテムを新規に再登録**していただく必要があります。

あらかじめご了承の上、ご利用ください。

> **1.4.0 以降をお使いの方へ**: JSON / CSV での書き出し・読み込みに対応しました。
> 今後プロジェクトを移行する場合は、移行前に「書き出し」でデータを保存しておけば、新しいプロジェクトで読み込み直せます。
> 詳しくは「[データの書き出し・読み込み](#6-データの書き出し読み込み)」を参照してください。

## 主な機能

- **アセット紐付け**: プロジェクト内のフォルダと販売ページ情報を統合管理
- **フォルダ階層選択**: インポートフォルダに配下フォルダがある場合、紐づけるフォルダをツリーUIで選択可能
- **自動情報取得**: BOOTHのURLから商品名・サムネイル画像・カテゴリー・ショップ名・価格・公開日を自動取得
- **取得可否の事前表示**: URLを入力した時点で、自動取得が可能かどうかと取得される内容を登録画面に表示
- **サムネイル複数選択**: BOOTHページ内の全サムネイル候補を一覧表示し、好みの画像を選択可能
- **重複登録の防止**: 既に登録済みのフォルダを登録しようとした場合に警告し、既存データの編集へ誘導
- **データの安全性**: アイテム保存時にテキストデータ（JSON）を自動バックアップし、万が一のデータ破損リスクを軽減
- **書き出し・読み込み**: JSON / CSV でデータを書き出し・読み込み。プロジェクト間の移行や表計算ソフトでの一覧化に利用可能
- **インポート検知**: `.unitypackage` の新規インポート時に登録画面を自動表示（ON/OFF切替可）
- **カラーハイライト**: 最後に登録したフォルダを上位2階層までProjectウィンドウ上でカラー表示（色は自由に設定可能）
- **カテゴリー同期**: カテゴリーをBOOTHの商品カテゴリーから取得して同期
- **ユーザータグ**: BOOTHのカテゴリーとは別に、自由なタグで分類（再取得しても消えません）
- **カテゴリー分類**: タブによる表示切り替えと、スリムな矢印でのスクロール
- **検索・ソート**: アイテム名・ショップ名・カテゴリー・タグ・URLを対象にした検索と、名前／登録日／BOOTH公開日／価格順での並び替え
- **販売状態の表示**: 販売終了・売り切れのアイテムをリスト上に表示
- **リンク切れの検出・再リンク**: 紐づけ先アセットが失われたアイテムを明示し、別のアセットへ再リンク可能
- **一括更新**: 登録済みアイテムの情報とカテゴリーを一括で最新の状態へ更新
- **日本語 / English**: 表示言語を切り替え可能

## 使用手順

### 1. ウィンドウの起動

Unityメニューの `UniMuse.lab` > `B-Manager` を選択してメインウィンドウを開きます。

### 2. アイテムを登録する

以下の3つの方法で登録できます。

| 方法 | 操作 |
|------|------|
| **右クリック** | Projectウィンドウのフォルダを右クリック → `Register to B-Manager` を選択 |
| **ドラッグ&ドロップ** | アセットをB-Managerウィンドウへ直接ドラッグ |
| **自動表示** | `Auto Open` を有効にしている場合、`.unitypackage` インポート時に自動で登録画面が開く |

> **注意**: Hierarchyウィンドウ上のオブジェクトは登録できません。Projectウィンドウ内の永続的なアセット（フォルダ）のみが対象です。

> 既に登録済みのアセットを指定した場合は、新規登録ではなく**既存データの編集**として開きます。

### 3. 登録画面の操作

#### フォルダ階層の選択
インポートしたフォルダの配下にサブフォルダが存在する場合、どのフォルダを紐づけるか選択できます。

- 登録済みのフォルダはグレー表示（✓登録済み）で選択不可
- 未登録のフォルダのみ選択可能
- ルートフォルダが既に登録済みの場合は、最初の未登録フォルダが自動で選択されます
- サブフォルダを選択した場合でも、Projectウィンドウのカラーハイライトは**一番上のフォルダから**適用されます

#### 重複登録の警告

選択中のフォルダが既に別のアイテムとして登録されている場合、警告が表示され保存ボタンが無効になります。
「既に登録済みのデータを開く」で、そのアイテムの編集画面へ切り替えられます。

#### ユーザータグ

BOOTHのカテゴリーとは**別の分類**として、自由にタグを付けられます。

- タグ欄に入力して Enter または「追加」で追加、タグをクリックで削除
- **再取得やカテゴリー同期を行っても、ユーザータグは変更されません**
- ツールバーの「タグ」ボタンからタグで絞り込めます

#### サムネイルの設定

| 設定 | 動作 |
|------|------|
| ☑ トップサムネイルを自動取得（デフォルト） | BOOTHページのメイン画像を自動で取得 |
| ☐ チェックなし | ページ内の全サムネイル候補を一覧表示し、好みの画像を選択可能 |

> 再取得時は、前回選択したサムネイルが引き続き存在する場合はそのURLを優先して取得します。
> サムネイルなしで登録したい場合は「入力内容のみで保存」を使用してください。

#### 自動取得の可否表示

商品URLを入力すると、ボタンを押す前に自動取得の可否が登録画面に表示されます。

| 表示 | 意味 |
|------|------|
| 自動取得: 判定中... | BOOTHへ問い合わせ中 |
| 自動取得: 可能 | 取得されるアイテム名・カテゴリー・ショップ名・価格をあわせて表示 |
| 自動取得: 不可（BOOTH以外のURL） | 「入力内容のみで保存」で手動登録してください |
| 自動取得: 不可（理由を表示） | 通信エラー・商品の削除など。理由が表示されます |

> 商品が販売終了・売り切れの場合は、この欄にその旨が表示されます。

#### 情報の保存

- **「情報を取得して保存」**: BOOTH URLを入力している場合に有効。商品名・サムネイル・カテゴリー・ショップ名・価格を自動取得して保存
- **「入力内容のみで保存」**: BOOTH以外のURLや手動入力内容をそのまま保存
- **「キャンセル」**: 登録画面を閉じます（データは保存されません）

保存データは `Assets/UniMuseData/B-Manager` フォルダに自動保存されます。

> **カテゴリーについて**: BOOTHのURLから取得した場合、カテゴリーはBOOTH側の商品カテゴリーで上書きされます（登録画面での手動選択より優先）。
> BOOTH以外のURLや「入力内容のみで保存」の場合は、登録画面で選んだカテゴリーがそのまま使われます。
> ユーザータグはどちらの場合も上書きされません。

### 4. 閲覧・管理

| 操作 | 内容 |
|------|------|
| アイテムをクリック | 該当アセットをProjectウィンドウでハイライト表示 |
| カテゴリータブ切り替え | 特定のジャンルのみを表示 |
| 検索ボックス | アイテム名・ショップ名・カテゴリー・ユーザータグ・URL を対象に検索 |
| タグボタン | ユーザータグで絞り込み（「タグなし」での絞り込みも可能） |
| アイテムを右クリック | URLを開く / 編集 / 再取得 / 再リンク / 削除などのメニューを表示 |

各アイテムには、カテゴリー・ショップ名・価格と、該当する場合は以下の表示が付きます。

| 表示 | 意味 |
|------|------|
| 販売終了 | BOOTH上で販売が終了している |
| 売り切れ | BOOTH上で売り切れ |
| アセットが見つかりません（リンク切れ） | 紐づけ先のフォルダが削除・移動された |

**右クリックメニュー詳細**

| メニュー | 内容 |
|---------|------|
| URLを開く | BOOTHページをブラウザで開く |
| URLをコピー | 商品URLをクリップボードへコピー |
| ショップページを開く | ショップのBOOTHページを開く（取得済みの場合） |
| 編集 | 登録情報を編集画面で開き直す |
| 再取得（カテゴリー同期） | BOOTHから最新情報を再取得し、カテゴリーをBOOTHと同期（BOOTH URLのみ） |
| Projectで選択中のアセットに再リンク | リンク切れのアイテムを、Projectウィンドウで選択中のアセットへ紐づけ直す |
| リストから削除 | BManagerデータのみ削除 |
| アセット本体も削除 | BManagerデータ + インポートフォルダを削除 |

> **削除時**: リストから削除を行うと、データファイルとバックアップ（JSON）の両方が整理されます。
> 削除の確認ダイアログには対象のアイテム名と削除されるフォルダのパスが表示されます。

### 5. カラーハイライトと設定

ツールバーの設定ボタン（⚙）から以下の設定が可能です。

| 設定 | 内容 |
|------|------|
| 表示言語 / Language | 日本語 / English の切り替え |
| 保存時にJSONバックアップを作成 | 保存ごとに、プロジェクトルート直下の `UniMuseData/B-Manager/Backup`（Assets の外）へテキストの控えを書き出す（ON/OFF） |
| バックアップフォルダを開く | 控えの保存先をエクスプローラーで開く |
| 最後に追加されたフォルダをハイライト | 直近の登録フォルダをProjectウィンドウ上でカラー表示（ON/OFF） |
| ハイライトカラー | 表示色を自由に変更可能 |
| ハイライトをクリア | ハイライト表示を手動で消去 |

> **ハイライトの範囲**: BOOTHのアイテムは「ショップ名 / 商品名 / ...」という階層でインポートされることが多いため、
> **上位2階層**（例: `ShopName` と `ShopName/ItemName`）を着色します。
> 登録画面のツリーでより深い階層を選んだ場合も、ハイライトは必ず一番上のフォルダから始まります。上の階層のほうが濃く表示されます。

### 6. データの書き出し・読み込み

ツールバーの書き出しボタンから利用できます。

| メニュー | 内容 |
|---------|------|
| JSONで書き出し... | 全アイテムを1つのJSONファイルへ書き出す |
| CSVで書き出し... | 全アイテムをCSVへ書き出す（Excelで開けるようUTF-8 BOM付き） |
| JSONから読み込み... | 書き出したJSON、またはバックアップのJSONを読み込む |
| CSVから読み込み... | CSVを読み込む（1行目をヘッダーとして列を判定するため、列順が違っても読めます） |
| バックアップから復元 | プロジェクトルート直下の `UniMuseData/B-Manager/Backup` 内のJSONをまとめて読み込む（旧バージョンが Assets 内に作った控えが残っていればそこも読む） |
| バックアップフォルダを開く | 控えの保存先をエクスプローラーで開く |

読み込み時の挙動:

- 紐づけ先は**アセットのGUID優先・パス次点**で解決されます
- 同じアセットに紐づく既存データがある場合は**上書き**されます
- 紐づけ先が見つからない場合は「リンク切れ」として登録されるので、右クリックメニューから再リンクしてください
- **サムネイル画像は含まれません**。読み込み後に「一括再取得」を実行すると取り直せます

## 技術的な補足

- 商品情報の取得には、BOOTH商品URLに `.json` を付けたエンドポイントを使用しています。
  1アイテムあたりのリクエストは「商品情報1件 + サムネイル画像1件」で、HTMLの解析は行いません。
- `.asset` に埋め込むサムネイルは最大辺512pxへ縮小して保持します。
- 一括再取得では、BOOTHへ連続アクセスしないよう1〜2秒の間隔を空けています。
- JSONバックアップは Assets の外（プロジェクトルート直下の `UniMuseData/B-Manager/Backup`）に置かれるため、Unity に取り込まれず、ビルドにも含まれません。
  バージョン管理に含めるかどうかは利用者が選べます。
